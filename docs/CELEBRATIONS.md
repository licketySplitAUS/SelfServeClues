# Adding celebration effects

The current catalog has **42 effects**: the original twelve, sixteen illustrated scenes, four experiment adaptations and ten cinematic typography shows. Every new scene has its own synthesized score; geometry is calculated from a fixed seed and elapsed time so audio and frame rates cannot change the choreography across panes. Scene work is bounded, with no external images, fonts, audio samples or added dependencies.

`public/celebration-effects.js` is the source for standalone Clues and download-capable Babble Expert. Add an effect ID and readable label to its `effects`/`labels` arrays, then implement its drawing and sound using the existing renderer lifecycle. IDs must match `[a-z][a-z0-9-]{0,39}`; keep IDs stable when improving an existing show. Keep the catalog at 100 effects or fewer and the generated pack below 512 KiB.

Run `npm run celebrations:build`. This generates the standalone browser bundle, `public/celebration-pack-v1.json` and the fixed server reporting labels. `npm run build` runs this step too. Run `npm run celebrations:check`, `node --test test/clues-celebration.test.mjs test/clues-fireworks.test.mjs`, `npm run typecheck` and `npm run build`. Exercise the effect's sound, reduced-motion message, transparent overlay, narrow/wide panes, replay and dismissal. For Expert, run its focused fireworks rendering/reporting tests with a fixture pack containing the new effect.

Deploy SelfServeClues through the normal authorized website workflow. Compatible additions then reach both standalone Clues and Expert without another installer release. All previously installed Expert versions need the initial release that introduces pack downloads; a website deployment cannot retrofit that capability. Updating Expert's bundled offline copy is optional for subsequent effects: run Expert's `node tools/sync-celebrations.cjs` when preparing a later installer.

The v1 feed contains `version: 1`, parallel `effects`/`labels` arrays and the self-contained `createBabbleCelebration`/`createBabbleFireworks` function sources. Preserve the options, returned controls and `onStart` effect/animation/seed contract. No Node APIs, external imports, new IPC operations or network dependencies belong in an effect. Expert supplies sound only in its right pane; the two overlays receive `sound:false`, the same chosen ID and seed. Reduced-motion shows must remain silent and must not consume rotation entries.

Both products persist a shuffled bag and its catalog. Each effect appears once before reshuffling; a new round avoids repeating the last show. Added effects join the remaining bag, removed effects leave it, and already-consumed effects remain consumed. Older bags without a catalog are migrated from the original twelve IDs: the new effects join their unfinished round while consumed originals stay consumed. Rotations belong to each browser/Expert profile; they do not synchronize across profiles or devices. Explicit previews and reduced-motion messages leave the normal bag untouched.

Expert requests only the fixed HTTPS feed, with redirects disabled, a 2.5-second deadline and a 512 KiB response limit. It checks at celebration opening, at most once per six hours when a cached pack exists; cached shows start immediately while refresh runs for a later opening. Without a cache, failed checks fall back to bundled shows and retry no sooner than five minutes later. Nothing downloads during startup. The pack is syntax-checked without running it in the main process. One snapshot supplies all three panes for a show; navigation and Hide invalidate pending starts. The offline preview always uses the bundled copy.

The four experiment adaptations are Æther (`aether`), Voice Canvas (`word-cloud`, labelled Found-word cloud), Protoplasm (`protoplasm`) and Fibre Tunnel (`fibre-tunnel`). Their motion is automatic; no microphone, camera, motion or pointer steering is requested. They retain the common show duration, fade, replay, reduced-motion handling and silent overlays.

The cloud accepts `options.words`: at most 10,000 alphabetic found words, 4–25 letters, deduplicated and sorted. All entries appear in groups of at most 30 within the show, rather than sampling the list. Expert supplies an atomic confirmed-word snapshot for the originating 25-letter grid, independently of journal recording; both overlays use the same snapshot. Standalone Clues uses the pure `GetCelebrationWords()` getter; legacy pages check checked answers against their decrypted clue words. Read current words afresh on every new show, never call bulk export to obtain them, and never infer missing answers. Unavailable words produce a quiet message. The offline preview uses labelled sample-puzzle words. Words are never stored in rotation/pack cache, hashes or reports. The standalone chooser derives all choices from the shared renderer.

Catalog upgrades put newly added IDs first in shuffled order, then resume the older unfinished deck. Removed IDs are discarded without resetting already-consumed entries. Keep IDs stable when editing an existing effect; a renamed or reintroduced ID is treated as an addition. Browser and Expert profiles keep independent decks.

Normal puzzle completion chooses a surprise. Play again repeats that chosen effect, seed and found-word snapshot without consuming another rotation entry. The five-click logo launcher enables the chooser for testing; Expert records this as `chooser=1` on the exact local document. P may show/hide controls but must never unlock the chooser for normal completion. Explicit test choices do not consume the normal rotation. Standalone replay retains normal mode and does not claim or report a new completion.

Standalone Clues ignores browser/OS reduced-motion preferences for completion, replay and secret previews. Pass `reducedMotion:false` explicitly at its rendering boundary. The shared renderer defaults to animation; only an explicit `reducedMotion:true` (Expert’s saved off choice or the offline test control) selects a silent static message. Expert still owns its embedded pages and honors Options → Show celebration animations across every pane.

The ten cinematic typography IDs are `monument`, `perfect-alignment`, `forged-gold`, `word-echoes`, `final-inscription`, `type-gravity`, `beyond-horizon`, `prismatic-language`, `silence-after` and `thousand-strokes`. They use local system fonts, bounded vector/text passes and per-show text metrics cached until resize. Letter trajectories depend on seed and elapsed time; no bitmap scans, remote fonts, assets or extra dependencies are required. The Silence After plays one decaying chord, then remains quiet for the rest of the show.

All ten typography scenes share a slow rainbow-light backdrop: six drifting radial glows, three spectral ribbons and a shaded text centre. Each scene has its own seeded palette/position phase; The Silence After moves more slowly. Overlays use lower opacity, and Expert’s explicit reduced-motion choice bypasses the backdrop entirely. Keep the work bounded and avoid blur filters or full-frame pixel processing.
